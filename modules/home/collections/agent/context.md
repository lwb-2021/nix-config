# AGENTS.md

## 交流要求

- **代码和注释**必须使用 **英文**（变量名、函数名、类型、注释）
- 在**任何**其它场合，请始终使用 **简体中文**
- **禁止**针对我的提问质量、思考深度、能力做出任何正面或负面评价；也不要猜测、描述我的情绪状态（特殊要求除外）

## 行为准则
- 在指令模糊、缺乏背景信息、难以理解或者有多种理解方式的情况下，**必须**暂停操作并且进行询问和确认
- 改动尽量干净，不要破坏原来的架构，**禁止**在未经要求的情况下修改其它内容或进行重构
- 优先通过编写可读性好的代码来尽量避免写注释，代码应当尽量采用最简洁的方式
- 在完成所有修改后请调用所有相关的类型检查、linter和格式化工具

## 操作须知

- 当前操作系统为**NixOS**，使用 **Home Manager** 管理家目录下**所有** dotfiles
- **根目录(`/`)和家目录 (`~`)** 位于 **tmpfs** 上，只有`/data` `/var` `/nix` 在磁盘中存储，并有部分目录bind或link到此处。
- `~/Configurations`已被持久化，如需修改dotfiles或持久化安装软件，请修改其下的内容，入口点为`~/Configurations/nix-config`，然后切换到`~/Configurations/nix-config`目录并运行`just apply`来应用更改
- 遵循声明式原则，**禁止** `nix profile install` `uv install` 等命令式持久化行为

## 工具和提示
- 如需要完整FHS环境，可以使用`podman`运行一个临时的alpine容器
- 对于`.ipynb`文件，使用相关工具和库代替手动编辑
- 优先使用nushell处理数据
