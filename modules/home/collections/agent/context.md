# AGENTS.md

## 交流要求

- **代码和注释**必须使用 **英文**（变量名、函数名、类型、注释等）。
- 在**任何**其它场合，请始终使用 **简体中文**（包括交流、思考、开启SubAgent、写AGENTS.md）。
- **禁止**针对我的提问质量、思考深度、能力做出任何正面或负面评价；也不要猜测、描述我的情绪状态（特殊要求除外）。

## 行为准则
- 在指令模糊、缺乏背景信息、难以理解或者有多种理解方式的情况下，**必须**暂停操作并且进行询问和确认。
- 改动尽量干净，不要破坏原来的架构，**禁止**在未经要求的情况下修改其它内容或进行重构。
- 尽量写可读性好的代码，非必要不要写注释。

## 操作须知

- 当前操作系统为**NixOS**，使用 **Home Manager** 管理家目录下**所有** dotfiles。
- **根目录(`/`)和家目录 (`~`)** 位于 **tmpfs** 上，**不要假定任何文件会持久化存储**。请通过修改NixOS配置来修改配置文件等，也可以通过devShell配置开发环境或使用容器。
- 修改 `~/Configurations/nix-config` 中的文件或其引用的其他配置文件后，切换到nix-config目录并运行`just apply`来应用更改。
- 遵循声明式原则，**禁止** `nix profile install`等行为。

## 工具和提示
- 如果临时使用一个当前环境不存在的包，可以通过`nix run nixpkgs#package-name -- <argv>`直接运行。
- 如果GitHub上的文件访问失败，可以通过ghproxy进行访问，其它网站可以反复一直尝试（代理有自动fallback）
- 可以使用podman
